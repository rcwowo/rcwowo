### 😵‍💫 Who is this?
**Hello!** My name is Riley Wilson. For awhile I was a video editor, but I've been working on a lot more web dev stuff as of late. I mostly stay in my own bubble and work on the things I care about - tools for Twitch streamers and viewers!

[Website](https://rcw.lol) • [Bluesky](https://bsky.app/profile/rcw.lol) • [YouTube](https://youtube.com/@rcwowo) • [Twitch](https://twitch.tv/rcwowo) • [Patreon](https://patreon.com/rcwowo) 

### 🛠️ Things I've worked on.
- [Peepochat](https://rcw.lol/project/peepochat) - a fully featured Twitch chat client built for the web.
- [Chatvoice](https://rcw.lol/project/chatvoice) - webapp to read Twitch chat messages out loud with your browser's built-in speech synthesis.
- [owoTV](https://rcw.lol/project/owotv) - an archival project for past livestreams, complete with chat replay and other search filters.
- [Emote Showcase](https://rcw.lol/project/emote-showcase) - a customizable Twitch extension to show off all your emotes, even third-party ones.
- [Wave Link Key Wrapper](https://rcw.lol/project/wave-link-key-wrapper/) - a Python script that added global hotkeys to Elgato's Wave Link software.
